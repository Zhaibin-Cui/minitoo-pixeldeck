# Sources / inspiration is not a bundled asset

## Protocol research

- [MiniToo findings](https://github.com/bugzmanov/divoom-minitoo/blob/main/FINDINGS.md): public investigation of command families and behavior.
- [Photo protocol notes](https://github.com/alvinunreal/divoom-minitoo-osx/blob/main/PROTOCOL.md): transport envelope, chunking and response examples.
- [Windows MiniToo tools](https://github.com/lewilou22/divoom-minitoo-tools): related independent experiments and useful context.

Pixeldeck implements the documented wire fields in its own protocol module. It does not include a copied upstream source file or apply the project's license to upstream work.

## Visual references

- [RoboEyes by FluxGarage](https://github.com/FluxGarage/RoboEyes): inspiration for expressive tiny-screen characters. No library code or eye animation frames are copied.
- [PICO-8 particles by MBoffin](https://mboffin.itch.io/pico-8-particles): inspiration for small, readable procedural effects. No cartridge or particle source is bundled.
- [Divoom MiniToo](https://divoom.com/products/minitoo/): reference for the general front-facing device silhouette. The repository device artwork is a stylized illustration drawn with code, not a manufacturer photograph.

All demo sprites, layouts, lettering and animation frames are generated by this repository. `tools/build_gallery.py` rebuilds the visual documentation. No paid font, logo pack, company branding or external sprite sheet is required.

Pillow and the platform runtimes remain their authors' work under their respective licenses. They are dependencies, not relicensed source copies in this repository.
