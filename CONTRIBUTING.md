# Contributing

Keep hardware I/O out of cartridges. A new demo should preview without a device and request no timer while static. Add a capability-map row for a new driver feature. Report whether evidence came from a fake socket, device ACK, or direct visual confirmation.

Run the test suite and regenerate gallery assets when a renderer changes. Public examples must use placeholder configuration and synthetic values. Do not add personal runtime directories, device identifiers, credentials, machine-specific paths, compiled bridge binaries, or unlicensed artwork.

Protocol changes need bounded buffers, explicit deadlines, and tests for missing responses. Avoid exposing undocumented destructive operations through a generic raw-send command. Optional experimental commands should be labeled as such in the capability map.

The release tool validates the public file set and creates an archive locally. Publishing a repository or release is a separate manual operation.
